# ClipAuto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dependable local web application that turns batches of YouTube videos into complete-topic vertical clips.

**Architecture:** A FastAPI process owns a SQLite job store and a bounded asynchronous worker queue. External media tools run as cancellable subprocesses, transcription runs in a worker thread, Ollama is called over its local HTTP API, and the browser polls durable job state while media and ZIP responses stream from disk.

**Tech Stack:** Python 3.12, FastAPI, SQLite, faster-whisper, yt-dlp, Ollama, FFmpeg, vanilla HTML/CSS/JavaScript, pytest.

**Spec:** `docs/spec.md`

## Global Constraints

- Preserve complete topics and sentences; never optimize for highlights or arbitrary clip length.
- Render 1080×1920 H.264/AAC MP4 with readable synchronized subtitles and no stretching.
- Select the smallest suitable installed Ollama model and validate every response.
- Bound concurrency for batches of 180–200 URLs and retain honest per-video progress.
- Stream or process media on disk; never load complete media into RAM.
- Use native `yt-dlp --cookies-from-browser brave` only as an access-error fallback.
- Backend ZIP creation must include all completed clips in the requested batch.
